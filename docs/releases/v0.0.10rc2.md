# v0.0.10rc2 Release Report

Release date: 2026-06-24

## Goal

This release improves the repository's GitHub presentation without changing
inference behavior. It makes the architecture, supported features, measured
performance, and current limitations visible before a reviewer reads the code.

## Changes

### GitHub landing pages

- `README.md` is now the English landing page.
- `README_CN.md` provides the synchronized Chinese version.
- Both pages include:
  - project positioning;
  - an ASCII architecture diagram;
  - a capability matrix;
  - a two-card Quick Start;
  - EvalScope benchmark tables;
  - current limitations and code navigation.

### Benchmark evidence

The README tables use selected measurements already recorded in
`docs/inference_performance_history.md`:

- Qwen3-32B fixed-length Greedy, concurrency 1: 24.7089 output tok/s;
- Qwen3-32B fixed-length Greedy, concurrency 4: 63.3523 output tok/s;
- Qwen3-32B fixed-length Top-P, concurrency 4: 57.7176 output tok/s;
- Qwen3-32B mixed-length Greedy, concurrency 4: 50.1580 output tok/s.

The README explicitly warns that different versions and workload shapes are not
strict apples-to-apples comparisons.

### Code documentation

Module-level docstrings now describe the responsibilities and correctness
constraints of:

- `lite_llama/continuous_batching.py`;
- `lite_llama/executor/model_executor.py`;
- `lite_llama/executor/npu_graph.py`;
- `lite_llama/executor/paged_attention.py`;
- `lite_llama/models/qwen3_moe.py`.

## Runtime impact

None. This release changes documentation, release metadata, and Python
docstrings only.

## Validation

- Repository documentation contract tests;
- Python syntax compilation for modified modules;
- Markdown local-link and encoding scans;
- existing focused scheduler, server, and Decode regression tests.
