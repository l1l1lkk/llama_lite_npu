# v0.0.9rc2 Release Report

Date: 2026-06-23

## Summary

`v0.0.9rc2` adds the first dedicated paged chunk prefill attention path for Chunked Prefill.

Before this release, Chunked Prefill could only run the first chunk through the packed-prefill / `flash_attention2_no_pad` path. Later chunks had to fall back to incremental replay because normal no-pad FlashAttention cannot see historical paged KV. This release adds a Triton `paged_chunk_flash_attention` kernel for later chunks:

```text
Q: current chunk tokens
K/V: historical paged KV + current chunk KV
Output: current chunk hidden states
```

## Changes

- Added `lite_llama/kernels/paged_chunk_flashattention.py`.
- Added `ModelExecutor.activate_paged_chunk_prefill_batch()` to build the required metadata:
  - request IDs
  - flat Q start locations
  - context lengths before the current chunk
  - current chunk lengths
  - current chunk KV cache write indices
- Routed Qwen3, Qwen2, and Llama text attention to `paged_chunk_flash_attention` when `atten_info.is_paged_chunk_prefill` is active.
- Updated Chunked Prefill scheduling:
  - first chunk: packed prefill using `flash_attention2_no_pad`
  - later chunks: paged chunk FlashAttention
  - fallback: existing incremental replay if the executor does not expose the paged chunk metadata path

## Expected Impact

This removes the largest structural bottleneck in Chunked Prefill later chunks: per-token model replay. It should mainly improve long-prompt TTFT and mixed-length concurrent prefill when `--chunked_prefill` is enabled.

This release is not yet an Atlas performance claim. It needs server-side correctness sweeps and MindStudio profiler confirmation before updating the README benchmark table.

## Known Limits

- The Triton paged chunk kernel still needs Atlas 910B3 runtime validation and profiler inspection.
- Decode NPU Graph is still decode-only. Chunked Prefill is intentionally eager because chunk lengths and prompt admission are dynamic.
- If the paged chunk path is unavailable, the runtime keeps the existing incremental fallback for correctness.
