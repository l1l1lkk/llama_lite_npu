# v0.0.12rc2 发布记录

## 版本定位

v0.0.12rc2 是 v0.0.12rc1 的依赖修复版本，不改变推理路径和调度逻辑。

服务器容器验证时发现 `requirement.txt` 中 `torch==2.7.0` 与 `torch_npu==2.7.1` 不兼容。`torch_npu==2.7.1` 依赖 `torch==2.7.1`，因此完整安装依赖会触发解析冲突。

## 修复内容

- 将 `requirement.txt` 中的 `torch` 从 `2.7.0` 对齐到 `2.7.1`。
- 保持 `torch_npu==2.7.1` 不变。
- 保持 v0.0.11rc1 与 v0.0.12rc1 的功能实现不变。

## 影响范围

- 不影响模型数值。
- 不影响 Decode NPU Graph。
- 不影响采样逻辑。
- 不影响 Continuous Batching 和 Adaptive Chunked Prefill。
- 只影响环境复现和容器内依赖安装稳定性。

## 验证重点

```bash
pip install -r requirement.txt
python -m unittest tests.test_vocab_parallel_sampling tests.test_continuous_batching tests.test_observability tests.test_server_batching -v
python -m compileall server.py lite_llama tests
```
