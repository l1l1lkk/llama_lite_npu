# Lite Llama NPU v0.0.3rc1

- 发布日期：2026-06-11
- 目标模型：Qwen3-30B-A3B
- 目标硬件：2 × Atlas 910B3
- 变更类型：MoE性能功能

## 相对v0.0.2rc2的更新

上一版本按命中专家执行Python循环：

```text
unique experts -> tolist -> for expert -> F.linear -> index_add
```

该路径会产生NPU到CPU同步、动态Python控制流和大量小MatMul。本版本改为：

```text
Router TopK
  -> Triton expert count + grouped Gather
  -> Ascend GMM Gate/Up
  -> Triton SwiGLU
  -> Ascend GMM Down
  -> Triton weighted Scatter
  -> TP AllReduce
```

## 实现细节

- `torch_npu.npu_grouped_matmul`一次提交所有专家的Gate/Up投影；
- SwiGLU继续复用项目现有Triton内核；
- 第二次Grouped MatMul执行所有专家的Down投影；
- Triton路由内核不使用`.tolist()`，路由计划始终保留在NPU；
- `group_list`使用每个专家任务数的累计结束位置；
- 空专家由重复累计位置表示，不为其执行有效矩阵计算；
- 运行时专家权重采用GMM原生`[expert, input, output]`布局。

转换后的`.pth`格式保持不变。加载器在CPU完成TP切分后一次性转置，因此现有Qwen3-30B-A3B权重不需要重新转换。

## 后端与逐层对齐

默认使用自动选择：

```bash
export LITE_LLAMA_MOE_BACKEND=auto
```

可选值：

- `auto`：NPU且GMM接口可用时使用GMM，否则使用eager；
- `gmm`：强制GMM，接口或设备不满足时直接报错；
- `eager`：使用v0.0.2rc2参考路径。

逐层数值验证：

```bash
export LITE_LLAMA_MOE_BACKEND=gmm
export LITE_LLAMA_MOE_VALIDATE=1
export LITE_LLAMA_MOE_ALIGNMENT_RTOL=1e-2
export LITE_LLAMA_MOE_ALIGNMENT_ATOL=1e-2
```

验证模式在每个Sparse MoE层中同时运行eager和GMM本地专家计算，并在TP AllReduce前比较结果。该模式会显著降低速度，只用于正确性排查。

## Atlas 910B3验证

先执行小规模真实NPU单元测试：

```bash
source /usr/local/Ascend/ascend-toolkit/set_env.sh
ASCEND_RT_VISIBLE_DEVICES=6 \
python -m unittest tests.npu.test_qwen3_moe_gmm -v
```

再执行双卡逐层对齐：

```bash
export LITE_LLAMA_MOE_BACKEND=gmm
export LITE_LLAMA_MOE_VALIDATE=1

ASCEND_RT_VISIBLE_DEVICES=6,7 \
python -m torch.distributed.run --nproc_per_node=2 \
  cli_qwen3_moe_tp.py \
  --checkpoints_dir /data/liuke/llama_lite_npu/my_weight/Qwen3-30B-A3B/ \
  --page_size 16 \
  --max_seq_len 4096 \
  --max_gen_len 16 \
  --temperature 0 \
  --disable_thinking \
  --no_compiled_model
```

对齐通过后关闭验证再测试真实速度：

```bash
unset LITE_LLAMA_MOE_VALIDATE
export LITE_LLAMA_MOE_BACKEND=gmm
```

## 已知限制

- MoE Decode NPU Graph仍保持关闭，需先确认GMM动态`group_list`的Capture/Replay兼容性；
- Triton Scatter使用FP32原子累加后转换回模型dtype，结果允许FP16容差范围内差异；
- 本地Windows环境不能执行NPU GMM，最终正确性和性能必须以Atlas 910B3结果为准；
- README性能区暂不加入Qwen3-30B-A3B预测数据。
