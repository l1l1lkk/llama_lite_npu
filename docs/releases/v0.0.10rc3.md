# v0.0.10rc3 发布记录

发布日期：2026-06-24

## 目标

为连续批处理文本服务增加可由 Prometheus 采集的运行指标，使 P99、QPS、
队列深度、KV 使用、NPU Graph 状态和失败归因可以直接观测。

## 新增能力

- `GET /metrics`：Prometheus 文本格式；
- `GET /debug/stats`：当前状态 JSON 快照；
- 请求成功、取消、失败和延迟统计；
- 排队时间、TTFT 与 ITL Histogram；
- Prompt 与生成 Token 计数；
- 等待、Prefill、Decode 请求数量；
- KV 页使用量；
- NPU Graph 捕获、回放和回退统计；
- 固定低基数失败分类；
- 非流式连续批处理请求在等待队列已满时返回 HTTP 429。

## 实现边界

- 仅 Rank 0 导出 HTTP 指标，TP Worker 不重复计数；
- KV 与 Graph 状态仅在抓取时同步，不进入每 Token Decode 热路径；
- 首版完整请求指标覆盖连续批处理文本请求；
- 不包含 Prometheus Server、Grafana 或 Kubernetes 配置。

## 性能影响

每个请求和 Token 只更新少量内存计数器及时间戳。KV 与 Graph 指标不会在
每个 Token 上访问设备状态。本版本不声明吞吐提升，后续应使用相同 EvalScope
工作负载验证指标开启后的性能开销。

## 验证范围

- 指标名称与标签测试；
- 请求生命周期与 Histogram 测试；
- 失败归因测试；
- 调度器事件接入测试；
- KV 与 Graph 快照测试；
- Server 路由契约测试；
- 现有连续批处理、Server 与 Decode 回归测试。
