# v0.0.8rc9 Release Report

Date: 2026-06-22

## Summary

`v0.0.8rc9` fixes a regression introduced in `v0.0.8rc8`: `ModelExecutor._infer_safe_prefill_tokens()` was inserted in the middle of `ModelExecutor.__init__`, making the remainder of constructor initialization unreachable.

The prefill-budget behavior from `v0.0.8rc8` is kept.

## Root Cause

The helper method was placed before this constructor section:

```text
self.max_request_num = ...
self.req_tokens_manager = ...
self.atten_info = ...
self._paged_prefix_cache = ...
self._paged_block_prefix_cache = ...
self.graph_runner = ...
```

Because Python method definition ended the constructor block, those attributes were never initialized. Rank 1 then failed during continuous-batching prefill:

```text
AttributeError: 'ModelExecutor' object has no attribute '_paged_prefix_cache'
```

## Fix

- Moved `_infer_safe_prefill_tokens()` below the full constructor body.
- Added a source-level regression test to ensure the helper remains after request-manager and prefix-cache initialization.
