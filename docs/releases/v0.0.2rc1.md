# Lite Llama NPU v0.0.2rc1

- 发布日期：2026-06-10
- Git Tag：`v0.0.2rc1`
- 新增模型：Qwen3-30B-A3B
- 目标硬件：2 × Atlas 910B3
- 精度：FP16
- 并行方式：专家内部TP=2

## 版本定位

`0.0.2rc1`在不改变现有Qwen3推理主链路的前提下增加Qwen3 MoE支持。首版目标是正确解析、转换和执行Qwen3-30B-A3B，不以MoE峰值性能为发布条件。

Qwen3-32B在`0.0.1rc1`建立的PagedAttention、Flash Decoding、OpenAI API和性能基线保持不变。

## 相对v0.0.1rc1的更新

### Qwen3 MoE模型

- 新增`Qwen3MoeConfig`和`model_type=qwen3_moe`注册；
- Attention、QK Norm、RoPE、KV Cache和LM Head复用现有Qwen3实现；
- Decoder仅替换FFN部分，支持配置决定Dense MLP或Sparse MoE；
- Qwen3-30B-A3B的48层默认全部使用Sparse MoE。

### Router与专家执行

- Router执行FP32 Softmax和TopK=8选择；
- 根据`norm_topk_prob`重新归一化TopK权重；
- 只执行实际命中的专家；
- 专家使用Gate/Up融合权重、Triton SwiGLU和Down投影；
- 使用routing weight加权并通过`index_add_`合并专家输出。

首版使用动态专家循环，便于与Transformers逐层对齐。该实现存在NPU Host同步和小矩阵启动开销，不代表最终性能路径。

### Tensor Parallel

Router在两卡复制，专家内部采用Megatron风格TP：

```text
Gate/Up：分别沿768中间维切分
Down：沿输入中间维切分
MoE输出：每层一次HCCL AllReduce
```

Gate和Up在切分前保持独立区间，避免将合并权重直接均分后造成Gate/Up布局错位。

### 权重转换

转换器支持官方权重命名：

```text
model.layers.N.mlp.gate.weight
model.layers.N.mlp.experts.E.gate_proj.weight
model.layers.N.mlp.experts.E.up_proj.weight
model.layers.N.mlp.experts.E.down_proj.weight
```

每层128个专家按数值ID顺序堆叠为：

```text
gate.weight                    [128, 2048]
experts.gate_up_weight         [128, 1536, 2048]
experts.down_weight            [128, 2048, 768]
```

转换过程中会消费已经堆叠的源专家张量，降低额外CPU内存峰值；任意专家权重缺失会立即报出层号、专家号和缺失键。

### NPU Graph

MoE专家命中由当前Token动态决定，首版动态循环无法满足固定Graph拓扑要求。因此：

- Dense Qwen3继续使用现有128-token Bucket NPU Graph；
- Qwen3 MoE传入`--compiled_model`时只输出一次警告并使用Eager Decode；
- 不进行失败Graph的重复Capture。

## 使用方式

### 权重转换

```bash
python apply_weight_convert.py \
  /data/models/Qwen3-30B-A3B \
  --model-type qwen3_moe \
  --device cpu
```

### 双卡CLI

```bash
ASCEND_RT_VISIBLE_DEVICES=4,5 \
python -m torch.distributed.run --nproc_per_node=2 \
  cli_qwen3_moe_tp.py \
  --checkpoints_dir /data/models/Qwen3-30B-A3B \
  --page_size 16 \
  --max_seq_len 4096 \
  --max_gen_len 1024 \
  --enable_thinking
```

### OpenAI兼容服务

```bash
ASCEND_RT_VISIBLE_DEVICES=4,5 \
python -m torch.distributed.run --nproc_per_node=2 \
  server.py \
  --checkpoints_dir /data/models/Qwen3-30B-A3B \
  --host 0.0.0.0 \
  --port 8213 \
  --page_size 16 \
  --no_compiled_model
```

## 最新性能基线

本版本尚未产生Qwen3-30B-A3B的Atlas 910B3实测数据。README继续展示已经验证的Qwen3-32B性能，不使用预测数据替代实测结果。

## 已知限制

- MoE专家执行是动态Python循环，Decode性能预计受Host同步和小MatMul启动影响；
- MoE暂不支持NPU Graph；
- 暂不支持Ascend Grouped MatMul、Expert Parallel或HCCL All-to-All；
- 暂不支持BF16和量化权重；
- 当前框架仍为单请求串行服务，不包含Continuous Batching。
