# v0.0.13rc2 发布记录

## 版本定位

v0.0.13rc2 是 v0.0.13rc1 的验证兼容性修复版本，不改变调度器逻辑。

## 问题

服务器容器运行：

```bash
python scripts/validate_release.py
```

时，`unittest discover` 会导入 `tests/test_torch_matmul.py`。该文件是一个可视化 benchmark 脚本，导入时依赖 `matplotlib`。

容器推理环境没有安装 `matplotlib`，因此 release validation 被可选绘图依赖阻断：

```text
ModuleNotFoundError: No module named 'matplotlib'
```

## 解决方案

将 `matplotlib` 缺失处理为 `unittest.SkipTest`：

```python
try:
    import matplotlib.pyplot as plt
except ModuleNotFoundError as exc:
    import unittest
    raise unittest.SkipTest(...) from exc
```

这样：

- 有 `matplotlib` 的环境仍可运行该可视化 benchmark；
- 没有 `matplotlib` 的推理容器会跳过该可选测试；
- release validation 继续覆盖核心推理框架测试。

## 影响范围

- 不影响模型推理。
- 不影响 Continuous Batching。
- 不影响 Decode Priority。
- 不影响服务器启动参数。
- 只影响测试环境兼容性。

## 与上一版本对比

| 项目 | v0.0.13rc1 | v0.0.13rc2 |
|---|---|---|
| Decode Priority | 已支持 | 不变 |
| Release validation | 可能被可选 matplotlib 依赖阻断 | 可选 benchmark 缺依赖时自动跳过 |
| 推理路径 | 不变 | 不变 |
