# v0.0.11-v0.0.12 Decode Sampling and Adaptive Scheduler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish v0.0.11 decode hot-path cleanup and v0.0.12 adaptive prefill scheduling without destabilizing current continuous batching.

**Architecture:** v0.0.11 keeps sampling on-device where practical, adds batched vocab-parallel Top-P candidate exchange, exposes fallback accounting, and avoids full-logit all-gather except when exact nucleus completeness cannot be proven. v0.0.12 keeps packed prefill as the default path, enables chunked prefill only for long prompts or explicit forcing, and documents the testing procedure used on Atlas 910B3.

**Tech Stack:** Python, PyTorch/torch_npu, HCCL tensor parallelism, EvalScope, Prometheus metrics.
