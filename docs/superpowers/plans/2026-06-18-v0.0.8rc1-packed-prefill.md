# v0.0.8rc1 Packed Prefill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v0.0.7 conservative mixed-length/chunked prefill path with a real packed prefill metadata path and release v0.0.8rc1.

**Architecture:** Keep the existing ContinuousBatchScheduler and PagedAttention model path. Add packed mixed-length prefill activation to the model executor, update the backend to run heterogeneous prompt lengths in one forward by flattening tokens, and keep chunked prefill token-budget behavior explicit. Exact prefix cache stays default-on; partial prefix cache remains opt-in.

**Tech Stack:** Python, PyTorch/Torch NPU-compatible tensor metadata, existing PagedAttention, existing unittest/pytest suite.
