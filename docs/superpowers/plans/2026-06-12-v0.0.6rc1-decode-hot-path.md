# v0.0.6rc1 Decode Hot Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove avoidable per-token Host and vocabulary communication overhead
from Qwen3 TP generation while preserving exact output behavior.

**Architecture:** Qwen3 models return local vocabulary shards. A shared sampling
module performs local or distributed selection, continuous batching retains
decode state on device, and a tensor command channel replaces decode-step Python
object serialization between TP ranks.

**Tech Stack:** Python, PyTorch distributed, HCCL, torch_npu, unittest.
